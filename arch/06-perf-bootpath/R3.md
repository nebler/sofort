## Reproduction and limits

```
make -C arch/jitk/bench build test
python3 arch/jitk/bench/run.py --samples 30 --gate-budget 10
```

`--max-extra-rounds` permits bounded additional attempts. The final run used
30 required + 30 extra blocks, gate budget 1 s. Exact explicit pins are retained
in `raw.json` → `config`; README documents validated override options.

Cold starts at spawn with warm file/signature caches; parked starts at RUN after
READY + 5 ms idle. Executor startup/pool preparation and reap are outside response
latency. Refill includes READY, kill and reap, four waves per batch. CPU is child
user+system through reap, excluding supervisor/watchdog CPU. Memory is process
RSS/physical footprint, excluding unattributed HVF kernel allocations. Sandbox
rows are a C probe of apply and profile-read+apply, not whole-VM subtraction.
JSON is 1 MiB internally, not a 1 MiB wire frame. CIs cannot remove contention or
serial dependence; quiet H4 and Linux metal performance remain UNVERIFIED.
