# Final architecture — keep B; earn the pool and the ABI claim

**FIXED:** withdraw the contended 27-ms boot-floor inference and the single-call
restriction; retain 03's measured 64-call concurrency. New n=30, load 15.46→15.02:
one-port bare/qjs **11.51/13.95 ms** median; no quiet-host claim or rebuttal of
the lead's 5.75/8.70 ms. Saturated samples are retained. All nine existing R1
proposals were read; 07/PROPOSAL.md is absent.

**Architecture:** one trusted TS executor/dispatcher owns tools, policy, bounded
queues, admission and lifecycle. It spawns one sandboxed panic=abort Rust/libkrun
worker per invocation: one vCPU, one inout console, external watchdog. A generated
RAW image maps unchanged stripped musl qjs at EL0 over Rust EL1; source bootstrap
speaks protocol v1 with 64 outstanding calls. No daemon, runtime ELF parser,
bytecode, snapshots, second authoritative decoder or second production backend.
Used VMs die; capacity remains charged until reap.

**D1–D14 verdicts:** KEEP D1/D3/D7/D9/D10/D11/D12/D13; CHANGE D2/D4/D5/D6/D8/D14.
Keep packing, but validate page permissions and generate physical/auxv metadata:
the R1 packer accepts RX/RW sharing a page. Generate a new 32-MiB layout: the
R1 stack ends at PA 0x82c00000, beyond RAM end 0x82000000. Recycle/zero mmap pages.
Pass epoch plus counter calibration. Keep reserved kernel framing only between
complete guest lines. Preserve the tiny Backend and its reaping promise; assign
one lifecycle owner. Reject unsupported SDK prelude/binary features explicitly.

**D14 experiment — MEASURED:** static-musl Lua 5.4.8 script and SQLite 3.50.4
in-memory query each pass 30 traced + 30 no-vDSO runs. Lua: **14 guest names,
+2** vs jitk's 17 (signal calls); SQLite: **13, +3** (also faccessat).
SQLite time/random: **16, +5** (also fcntl/getpid). Base-run load 26.72→27.24;
richer run 136.86→75.75. Both base fixtures pass 30/30 with signal ENOSYS and
guard rejection combined. Choose **Lua + embedded read-only script first**:
**200–350 extra kernel LOC, UNVERIFIED**; SQLite base 200–350, richer 300–550.
Counts are observed surfaces, not full-runtime compatibility. Real-VM execution
remains unverified; use a separate pinned capture harness for ordinary stdout.

**Owned LOC planning caps, UNVERIFIED, physical source including tests:** guest
1,700 (including Lua profile); Rust VMM/confinement 500; TS framing/policy 550;
executor/pool/lifecycle 400; JS bootstrap 150; packer/layout 150; grow controller/
oracle 850; Hyperlight comparison adapter 150; independent tests 1,300.
**Total 5,750 LOC**, excluding generated/vendor code and external security audit.
01/02's live R2 work is evidence to integrate, not a reason to implement it again.

**M0–M4:** M0 freeze working kernel/image/CLI/v1 contracts; validate layout, clocks,
reuse and actual execute→2. M1 solve full qjs ppoll parking and reverse-order
64-call virtio; only then pool. Prefer GIC+WFI, measure isolated timer fallback;
pre-spawn/build-on-demand still needs sleeping during tool waits. M2 delete one
real handler, regrow through Linux oracle + bounds tests, then run unchanged Lua;
show build time separately. M3 merge security-owner gates and compare identical
snippets against fresh-worker **snapshot-backed Hyperlight**, including generic
source compilation. Its 1.87-ms in-worker / 9.30-ms whole-process result and
0.295-ms logical clone are distinct contracts. M4 run 10k KVM invocations at
concurrency 1/32/256, including misses/refill/reap, CPU and attributable memory.

**Kill criteria (targets):** no pool at ≥2% idle core/VM or any stall in 1,000
exchanges; aggregate parked/waiting CPU ≤10% host capacity. Stop public exposure
on policy/isolation bypass or >50-ms deadline overshoot at admitted load. At M4,
reject custom-kernel investment if overhead p99 >10 ms at c32, >5 CPU-ms or
>32 MiB attributable memory/invocation. Drop the JS-only pitch if equivalent
Hyperlight is within 20% on density/throughput. Stop ABI expansion if the Lua
profile exceeds 350 incremental kernel LOC or needs signal delivery/threads/
general files. Parking integration, real growth and Linux measurements remain gates.
