# Public claims ledger

Only the claim and scope in a supported row may be repeated publicly. Confidence
is confidence in that bounded observation, not a probability of future safety.
HIGH = independently reproduced integrated artifact; MODERATE = owner receipt
with exact artifacts; LOW = source inspection or old artifacts; NOT CLAIMED =
no current evidence, missing gate, or a broader inference than the evidence.
R2 evidence is historical and does not pass an R3 gate. `.READY` is coordination.

NOT CLAIMED: quiet-host latency when load gates fail; Linux performance from
nested virtualization; production exec/s or density from macOS projections;
total memory from configured guest RAM, RSS or process footprint; full Linux
ABI/POSIX/QuickJS/SDK compatibility from selected fixtures; arbitrary static
binary support from Lua; secure execution of malicious build-time proposals;
universal Hyperlight inability to run Lua; a whole product of 1–1.5k LOC; complete
escape resistance or freedom from vulnerabilities from a finite attack suite;
Linux signal delivery from always-ENOSYS profiles; a Lua failure-before/growth-
success narrative (absent slots also return ENOSYS); live R3 model sampling
(the controller installs reviewed proposal artifacts; live headless R2 evidence
is historical); current cloud prices or a measured fresh-machine build budget.

The benchmark owner owns statistics. No latency table is copied here; all new
performance claims must name the canonical row, artifact hashes, timing boundary,
sample count, load/gate status and mode's hardware-isolation contract. A p99 at
n=30 has weak tail resolution and cannot establish a production SLO.
