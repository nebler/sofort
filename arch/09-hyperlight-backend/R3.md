## Method

Apple M4 Pro / macOS 26.6.1; all exact R2 JS bodies. One 5 ms echo tool and
Promise.all(10) use the controller's same asynchronous response scheduler.
JSON constructs exactly 1,048,576 JSON bytes internally and returns the length;
the 50 ms loop uses Date.now, so this is wall-clock work, not fixed CPU cycles.
Cold begins before spawn; parked begins immediately before RUN after READY +
5 ms idle. Both end at validated done, before kill/reap. Cache/signature
admission is warmed by untimed validation. Refill cost remains outside parked
latency and is retained in raw lifecycle fields where available.

The gate attempts load1 <6 for 0.1 s per sample, then flags timeout and records
uptime/load. Thirty seeded interleaved complete blocks contain all 25 latency
cells and 5 memory configurations. No modes run simultaneously in this harness.
Paired 95% bootstrap CIs resample the same 30 blocks 10,000 times and compare
medians. They do not remove shared-machine contention or temporal correlation.
p90/p99 use 06's interpolated order statistics; n=30 p99 is poorly resolved.

Memory uses external macOS proc_pid_rusage V0 footprint and RSS, five readings
per parked process, 30 independent processes/configuration. RSS can count shared
file-backed pages; footprint is not PSS. HVF kernel allocations, system page
cache and supervisor/tool memory are not attributed. No host-wide density claim
can be inferred from these per-process counters.
