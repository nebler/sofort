## FIXED — E4 resolve before reap

Validated done resolves execute. Timer/listener cleanup and scheduling only are
on the successful result path. setImmediate defers SIGKILL, host-tool abort, both
child reaps and refill until after the caller's continuation. The abort→kill
listener is detached before deferred cancellation. A capacity token remains held
through both VMM and independent watchdog closes; used VMs never return to reserve.
A deterministic test independently delays both reaps: result precedes even kill,
and reaping only the VMM never releases capacity. Close drains all owned work.

Bounded acquisitions can await already-running background refill, preventing
spurious sequential shedding while launch slots are occupied by refill. Actual
capacity exhaustion still sheds explicitly; pool.drain() allows cold pacing.
