### Native GIC path and the lost-wakeup correction

Runtime host diagnostic explicitly says **JITK_GIC hvf**. FDT GICD is
`0x09fd0000`, GICR `0x09fe0000`, console SPI **33**; userspace GicV3 would put
GICR at `0x09fb0000`. This macOS 26.6.1 therefore uses native **HvfGicV3**.
The guest initializes GICD/GICR/ICC from FDT, targets affinity0, enables IRQ33,
sets edge trigger (libkrun asserts true without deassert), and keeps IRQ/FIQ
exceptions masked in EL0 and EL1. It drains virtio interrupt status and consumes
IAR/EOI. Crucially, it **rechecks DMA used rings after IAR/EOI, before WFI**.
Our initial cached-readiness check lost a completion racing IRQ acknowledgement;
the timer hid that bug. The fresh ring check fixes the IRQ-only stall.

The source concern was real but its initial inference was wrong:
`devices/src/legacy/hvfgicv3.rs:136` calls only `hv_gic_set_spi`; it does not send
`VcpuList.wfe_sender`. Trapped WFx at `hvf/src/lib.rs:808` can indeed enter
`vstate.rs:557`'s userspace-channel wait. **Native WFI does not take that path**
when the GIC is initialized: area 01 instrumented zero calls to wait_for_event
through 1000 native WFI wakeups; its forced userspace run takes that path and
also passes. Apple/HVF handles native WFI sleep/SPI wake inside hv_vcpu_run.
Our timer-disabled 1000-exchange result independently verifies wake/liveness.
**No libkrun patch is needed for A on this OS.** Do not force userspace GIC
merely from the channel-source reading. WFE is not the chosen primitive.
Supporting investigation: `r2/gic-findings.md`, `../01-vmm-host/r2/PARKING.md`.
Linux/KVM parking remains **UNVERIFIED** on this machine.

## ABI, memory, clocks and console

- **ppoll 73 FIXED:** fd0 POLLIN only with buffered bytes; EOF reports HUP,
  not false POLLIN. NULL waits use IRQ-only WFI; finite waits arm CNTV and
  respect the deadline. Empty finite nfds=0 sleeps too. Negative fds ignored;
  unsupported fds report NVAL. Invalid timespec/user memory is rejected.
  QuickJS setTimeout(5ms) + asynchronous stdin, n=30, completes without false
  read callbacks or blocking read. n=30 E2E p50/p90/p99 **38.874 / 109.796 /
  217.167 ms**, load **78.94 / 89.31 / 56.68**. These include spawn/boot/5ms.
  `mremap` 216 explicitly returns **ENOSYS** (musl fallback).
- **munmap recycling FIXED:** deterministic VA→PA mapping allows the free-page
  set to be represented by invalid PTEs, with bounded first-fit contiguous-page
  search instead of duplicate linked-list metadata. munmap clears PTEs; mmap
  reuses holes and zeroes recycled pages. The arena has 5,632 pages. brk remains
  separately bounded. `r2/churn.js` allocates/releases **128 MiB cumulative**
  (one 1MiB array live), returns **8128** in **32 MiB**, with the 16MiB qjs cap.
  This is real qjs/musl mmap churn, not a host allocator simulation.
- **REALTIME FIXED:** host passes paired `jitk.epoch_ns` and `jitk.counter`;
  kernel adds CNTVCT delta to that origin. Host chooses the least-preempted of
  eight bracketed wall/counter samples. Epoch-only launchers fall back to
  kernel-entry origin and do not get a sub-ms claim. `r2/clock-check.json`,
  n=30, compares guest REALTIME−CNTVCT with host REALTIME−mach counter,
  eliminating transport RTT. Worst absolute error bound **0.963ms**, including
  Date.now's 1ms quantization; signed p50/p90/p99 **−0.455/−0.030/−0.005ms**.
  Guest bracket width 0.00025ms. Load **36.09 / 74.53 / 54.23**.
- **Console D7 FIXED:** console reg/IRQ discovered in bounded FDT parser;
  all eight control buffers posted before DEVICE_READY, completions drained
  and reposted, PORT_OPEN=0 becomes EOF; RX preserves tails across partial
  reads. Tests pass for one-byte run fragments, 32KiB return frames, and EOF
  termination without a successful done (`r2/checks.json`).
- A libkrun control-RX-kick defect was found: in
  `devices/src/virtio/console/event_handler.rs:139`, that branch consumes the
  kick but does not call process_control_rx. With one offered buffer, queued
  setup messages could strand EOF. Eight initial buffers cover this fixed
  one-port topology (three setup messages + EOF). Smallest host completeness
  fix: after reading that kick, also call process_control_rx. It is not needed
  by this artifact; general console hotplug/terminal resize is not supported.
- **D8 FIXED:** kernel records start 0x1E. stdout controls except LF kill EL0;
  entire writev is validated before emitting any prefix; zero-length iovecs
  are accepted (required by musl). fd2 is dropped. If stdout is mid-line,
  diagnostics terminate silently rather than splice into the guest frame.
  Direct os.write of `[0x1e, LF]` is killed; no forged kernel record escapes.
  Guest JSON remains untrusted intent; 03/04 own host validation/policy.

## D2 packed-image measurement

Build-time `r2/prepare.py` validates the static ELF and emits a flat qjs image
and trusted segment constants. qjs is loaded at final PA **0x80080000**;
EL1 maps its RX/RW pages in place, including initialized/zero BSS pages.
There is **no guest ELF parser, PT_LOAD copy, or guest qjs BSS clear**.
AT_PHDR/ENTRY remain correct. Text's privileged alias is RO/NX; EL0 text RX,
mutable pages RW/NX; PAN and EL0/EL1 separation retained.

Formatted runtime-loader comparison: user.rs **469→431 LOC (−38)**, including
all the other identical syscall changes. Final guest Rust+assembly+generated
four-line manifest: **1,218 physical LOC** (round 1 was 901; delta +317).
Trusted bootstrap JS is separate, 123 lines. No guest dependencies/crates added.

Interleaved n=30 pairs, packed vs runtime ELF-copy baseline, same host/bootstrap:
ready p50 **29.396 vs 34.072ms**; p90 **58.322 vs 69.158ms**; p99
**101.194 vs 95.757ms**. Paired packed-minus-loader median **−2.479ms**;
p90 **+32.522ms**, p99 **+67.342ms**. Load **37.87 / 52.12 / 48.37**.
Variance is too large to establish a reliable boot speedup. The structural
copy/parse removal and memory saving are certain; latency benefit is noisy.
RAW sizes: packed **2,924,544**, runtime-copy **2,416,657 bytes**. The packed
image is larger because final PA reserves a 512KiB kernel/stack prefix; this
is an explicit +507,887-byte packaging tradeoff, not hidden as a size win.
The 2.4MB qjs source/destination duplication in guest RAM is removed.
Reproducer: `r2/compare-loader.py`, `r2/boot-compare.py`; raw JSON retains pairs.
