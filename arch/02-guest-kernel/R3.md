## Canonical layout and grow contract

- One handler per `src/syscalls/<name>.rs`. build.rs generates fixed dispatch
  slots from slots.json; missing files need no other edit. 134/135 are reserved
  and installed as explicit always-ENOSYS Lua profile handlers (6 LOC total).
- ioctl uses 08's agent-grown handler: bad fd -> EBADF, TIOCGWINSZ -> ENOTTY,
  unsupported command -> ordinary ENOSYS. mremap is also ordinary ENOSYS.
- ppoll adopts 08's checked copying, timeout overflow validation, signal-mask
  refusal, negative-fd ignore, stdout/stderr POLLOUT and unknown-fd POLLNVAL;
  retains r2 stdin HUP/readiness and WFI/CNTV waits. No busy-poll loop. A separate
  input-interest flag prevents buffered stdin from spinning nfds=0 timeout waits.
  Candidate helpers expose both park(deadline) and park_poll(deadline,input).
- A deleted handler ALWAYS yields -38 and an RS-prefixed v2 missing record.
  A registered handler returning -38 does not. The actual copied-kernel tests
  distinguish ioctl, mremap and unknown nr511, then delete ioctl and rebuild.
- grow-trace preserves 08's sys.enter/missing/sys.exit/done schema, byte captures
  and fd2 hex logs. Deferred trace records cannot split a guest line (16 KiB
  bound, fail closed on overflow); tested using two partial stdout writes.
- JITK_ELF, JITK_ARGV_JSON, JITK_SCRIPT, CARGO_TARGET_DIR and JITK_OUT_DIR isolate
  grow builds. A custom executable is static ET_EXEC, VAs 0x400000..0x680000.
  README specifies argv, helper API, feature flags and every record field.
- Default qjs argv reads the shared protocol/bootstrap.js through include_str!;
  no bootstrap copy. 03's Unicode clipping and DEL checks are included.

## Packer and retained properties

prepare.py explicitly rejects W+X and ANY PT_LOAD page overlap, including a
crafted byte-disjoint RX/RW pair occupying the same page. Five packer tests pass,
including proper BSS zero-fill and loaded PHDR validation. The r2 packer already
had an overlap check; this round makes the rule and its regression executable.

32 MiB remains sufficient: kernel/EL1 stack end **0x80057000** (link-time assert
below 0x80080000); EL0 stack ends at PA **0x81c80000**, below RAM end 0x82000000.
Packed qjs starts at PA 0x80080000; no guest ELF parsing/copy. mmap holes recycle
through invalid PTEs, brk remains bounded, qjs has a 16 MiB cap. PAN, RX kernel
aliases and EL0/MMIO isolation remain. Console discovery is FDT-based, control
buffers are drained/reposted, EOF is HUP after buffered input, partial reads work.

Both write and writev reject everything outside printable ASCII plus LF BEFORE
emitting any prefix; writev validates ALL iovecs first. Explicit valid-call-LF
prefix + NUL/RS/DEL/0x80/0xff in the same write produces **zero callbacks** in all
five checks. Production fd2 is dropped. D8 partial-line termination is retained.
