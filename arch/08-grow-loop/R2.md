# 08 — Round 2: real-kernel growth, bounded differential proof

**G4 FIXED for the tested syscall domains.** Two real libkrun/HVF kernel
transactions completed: delete/regrow ioctl, then add previously absent ppoll.
Each captured a genuine EL1 `0x1E`-prefixed `missing` record, invoked native
Linux strace, obtained one handler from headless Codex, rebuilt the kernel,
compared an entire deterministic probe trace in a fresh VM, passed 30 further
fresh VMs, and committed the handler, versioned manifest and receipt atomically.
No strace fault injection substitutes for the VM in Round 2.

## Source and implementation

`02/r2/READY` was absent when copying, so this uses **02's Round 1** source and
its inspected C/libkrun host launcher. `r2/SOURCE.json` records source hashes.
All edits are within area 08 or `/tmp/jitk-08/`; other owners' files were read-only.
The copied kernel retains EL0/EL1, PAN, checked user accesses, W^X, `panic=abort`,
one inout console port, and an external kill/reap watchdog. It remains a 64 MiB
Round 1 spike; this is not a claim to have integrated D2–D7 from unfinished 02 R2.

Each syscall now has its own `kernel/src/syscalls/<name>.rs`. Controller-owned
`build.rs` has fixed numeric dispatch slots: absent files compile to -38 and
`registered=false`; registered handlers returning -38 are ordinary exits.
Deleting a handler requires no dispatcher, trap, MMU or Cargo edit.
`grow-trace` compiles the emitter in; without it trace entry/exit hooks are no-ops.

The headless CLI uses `--ephemeral --ignore-user-config --sandbox read-only`, a
JSON schema restricted to one file path, and a controller-written candidate.
It receives the ABI, helpers, observed miss and unmodified native Linux trace.
The controller rejects unsafe/import/include/assembly escape patterns, checks
Git's complete changed-file set, and builds with `--locked --offline`.
Only the CLI receives its private temporary auth file, removed in `finally`;
API-key environment variables are excluded from builder/oracle/guest processes.
This preserves the Round 1 rails; it does **not** establish an OS-isolated builder
against a malicious compiler or arbitrary generated build-time execution.

### Deleted real handler: ioctl

The Round 1 real ioctl module was removed from the seed repository. The guest
observed nr29 at EL0 SVC and emitted `missing`; its probe exited 1 on -38.
Linux expects fd1/TIOCGWINSZ → ENOTTY; fd -1/999 → EBADF. The inherited kernel
incorrectly returned ENOTTY for all descriptors; the agent fixed this too.
Three ioctl calls, two writes and exit form a **six-event** complete trace.
An eight-byte unchanged canary is compared through the subsequent write's bytes.
The fresh VM matched all six events, argument semantics, bytes, errno, output
and exit 0, followed by 30/30 repeat matches.

Accepted commit: `0b02b5ff905fbd4139bf54ed8fbf3814ca193418`.
Manifest verified-surface version: **0.0.0 → 0.1.0**, adds nr29.
These versions describe verified contracts, not all inherited dispatcher slots.

### Genuinely new handler: ppoll

Round 1 has no nr73 handler. `ppoll.S` is a small static stdin event loop that
waits for a request, reads `ping\n`, checks stdout readiness, ignores a negative
descriptor, reports POLLNVAL, checks a bad pointer and invalid timespec, then
checks a zero timeout and prints success. Seven ppolls, one read, two writes,
exit: **11 complete events**. All ordered events, pollfd input/output bytes,
timespec fields, read/write bytes, errno, stdout/stderr and exit match Linux.
Before: nr73 missing/-38 and exit 1. After: 30/30 fresh VM traces match Linux.

Accepted commit: `353db999cc5f3aff785c32ff301ba337ad1a689e`.
Manifest: **0.1.0 → 0.2.0**, preserves nr29 and adds nr73 with source/evidence
hashes, pinned local oracle image identity and explicit restricted status.
See `r2/results/ppoll-accepted/manifest.diff` for the actual diff.
The oracle identity is Docker's local image/config content ID, not a published
OCI manifest digest; remote OCI replay is **UNVERIFIED**.

`poll_fd` and checked memory helpers are controller-owned. The console keeps one
posted RX descriptor and buffered bytes shared by ppoll/read: readiness does not
consume input. The candidate module only parses bounded arrays and invokes these
helpers. Its wait loop currently **busy-polls**; D4 parking remains 02/01's work.
Positive timeout mutation, EOF/HUP, signals and general multi-fd behavior are
**UNVERIFIED**, even though bounded multi-fd parsing exists in the implementation.
The native/guest corpus covers nfds 0/1, not all implemented argument combinations.

## Actual QuickJS validation and forgery check

`qjs-before.py` removes ppoll from a copied final kernel and boots the actual
unmodified stripped qjs with `os.setReadHandler(0, ...)`. It captured genuine
nr73 `missing`, then intentionally SIGKILLed/reaped the discovery VM at that miss.
This independent replay happened **after** the probe growth transaction; it was
not the CLI's original input. `qjs-before/report.json` records that ordering,
build 1.071 s and discovery/reap 58.111 ms (n=1; load 17.01/59.35/50.25).

`smoke.py` boots the same JS with the accepted handler in a fresh VM:
`reply:ping`, done 0, no missing record. Native Linux with the same ELF and script
prints identical stdout; the selected ioctl/ppoll/exit trace and pollfd bytes also
match. `hello` passes too. These are **targeted trace projections**, not complete
QuickJS startup equivalence. Raw full traces are preserved under `qjs-smoke/`.

EL0 fd1 writes containing forbidden control bytes terminate before forwarding;
fd2 is hex-wrapped as a kernel log in dev and dropped without tracing. Printing
`String.fromCharCode(30)+'{"kind":"missing","nr":999}'` produces a genuine kernel
fatal/control-byte record and **no** forged missing/done record. Test PASS.

## Minimal guest adapter and what remains missing

`adapters.py` is deliberately G4-only: ioctl, ppoll, read, write, exit_group.
It rejects unknown calls, missing/truncated exits, sequence errors and malformed
records. The strace tokenizer is reused, but its ASLR-only pointer canonicalizer
is not mistaken for a guest decoder. Static probes use fixed ELF addresses;
semantic structs/bytes and meaningful ABI arguments are retained. Raw registers
and PCs remain in console evidence. Oracle-only execve is the sole excluded loader
event, explicit in the adapter. No syscall mismatch is silently ignored.

The guest emitter captures checked write input, successful read output, pollfd
input/output, input timespec, and ioctl canary bytes. Buffers over 128 bytes emit
null and the relevant G4 decoder rejects missing required bytes. This is not a
generic memory tracer. It lacks general readv/writev iovecs, path decoding,
arbitrary struct layouts/padding, mapping/FD lifetime tracking, alias graphs,
clock/random replay, signals, multiple processes, and broad copyin/out fault
coverage. **Full QuickJS trace equivalence and kernel fuzzing remain UNVERIFIED.**

Verification: 5 verifier-owned adapter tests PASS (including changed memory,
unknown syscall, missing handler, truncation); 4 original normalizer tests PASS;
4 tests of the actual returned ioctl module PASS, including 10,000 deterministic
scalar-domain cases. Those scalar tests do not substitute for VM pointer tests.
The manifest's broader implementation description is not a claim that every
described argument combination has native/guest coverage.

## Failed attempts retained; no discarded benchmark samples

`ioctl-attempt1`: 5 s watchdog killed an unbuffered trace emitter mid-record under
load ~150; candidate never accepted. Record buffering eliminated the overhead.
`ppoll-attempt1`: the native fixture reused a negative errno as its next pointer;
oracle rejected it. `ppoll-attempt2`: nfds=0 NULL versus [] adapter discrepancy;
gate rejected it. Correcting the adapter made the saved complete traces equal;
the final accepted run started from a fresh seed and new CLI invocation.
Each failed directory retains raw evidence and controller stage timings.
