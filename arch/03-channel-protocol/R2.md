## Binding artifacts

- `PROTOCOL-v1.md` is the single normative spec (162 lines, below 200).
  D10 message set only; args arrays, consecutive IDs, one run, exclusive ok/err.
  It supersedes both round-1 proposals and their old bootstrap/parser sketches.
- `r2/bootstrap.js` (128 lines) is the final source module for 02/04 to consume.
  Stock std/os, setReadHandler, lexical Proxy namespaces from run.ns,
  AsyncFunction body, timers and bounded structured console logs; no bytecode.
- `r2/dispatcher.ts` (229 lines) is the dependency-free trusted TS implementation.
  Runs directly under absolute Node 24 with built-in type stripping; strict
  TypeScript typecheck passes. No runtime npm package or Rust decoder is used.
- `r2/vectors.json` is a language-independent, generated conformance corpus.
  Its format description is embedded in the file; `make-vectors.py` regenerates it.
  Host steps carry JSON objects; guest steps carry exact UTF-8 wire text;
  repeat expands a step and EOF is explicit. Errors stop a case immediately.

## Lead objections resolved

1. **FIXED — incompatible protocols.** Every new runtime/test uses ready(v=1),
   run(code/body,ns), call(args ARRAY), ret, log(msg), done. No version alias,
   providers/hello/code/result/fatal/error message remains in the new runtime.
   Undefined final/tool results normalize to null; both branches require values.
   Fixed defaults include 64 KiB decoded UTF-8 code and prior 03's byte/log budgets.
2. **FIXED — source bootstrap on stock static qjs.** Both native and the exact
   supplied `/tmp/jitk-spike/sc/qjs-static` pass 30 fresh runs of 64 concurrent
   calls with replies sent 64→1. Unicode, variadic args, caught DENIED errors,
   all five console levels, timer and final value are checked on every run.
   Each backend separately checks 2,000 logs produce exactly 1,024 records.
   Five additional terminal-error scenarios pass on each backend: syntax,
   TypeError, BigInt, unawaited call, and error done cancelling pending work.
3. **FIXED — Rust/TS ownership conflict.** One TS process decodes and dispatches.
   A bounded structural pre-scan rejects duplicate decoded keys at every depth;
   JSON.parse decodes key escapes and the full document. This is one authoritative
   JSON implementation, not a Rust/JS parser disagreement boundary. The scanner
   only counts structure and identifies object keys; JSON.parse validates grammar.
   No measured need for a separate Rust security boundary exists in this design.
4. **FIXED — strictness/budgets ported.** The dispatcher checks incoming total
   bytes before retaining a chunk, validates each byte and frame capacity before
   accumulation, and bounds depth/structure before parsing. Buffer growth is
   geometric and capped at 1 MiB, with no fragment-array amplification. Strict
   direction/schema/state checks, scalar Unicode/numbers, call IDs, outstanding,
   inflight bytes, total bytes/frames and UTF-8 log budgets precede callbacks.
   Kill poisons state and fires once. Refused host queue admission releases no
   response credit or state; accepted ret retires its ID before continuations.
5. **FIXED — stdout forgery/framing ambiguity.** D8 is explicit: RS-prefixed kernel
   text is opaque diagnostics, not another JSON message namespace. It cannot
   authorize calls or establish success. EL0 control-byte writes kill; fd2 is
   dropped in prod/wrapped in dev. Mid-frame diagnostics must be deferred or the
   VM terminated. Synthetic kernel records, fragmentation, caps and accounting
   are tested. Actual kernel enforcement remains 02's integration responsibility.

## Integration / remaining gates

02 consumes the bootstrap as a source file (`qjs -m ...`), with ppoll fd0 readiness,
finite timeout/clock support, partial reads, EOF, and the D8 kernel write rules.
04 imports Dispatcher and implements its bounded partial-write-safe FIFO:
`feed(Uint8Array)`, `send(frame, enqueue)`, `eof()`, `cancel(code)`.
`enqueue` is synchronous/all-or-nothing; false means retain/retry. Node writable
`write()` returning false means accepted with backpressure, NOT queue refusal.
Do not reenter feed from callbacks. Apply policy and own-property tool lookup to
all call events, including methods absent from the manifest; the decoder grants
no capability. On done/cancel, abort tools and discard late completions before
calling send. Bound/freeze the exact validated policy snapshot and all SDK work.

G2 over **actual virtio-console**: UNVERIFIED here; 02/04 must run the same harness
through their real backend. G1 parking idle CPU/1,000 exchanges and G3 actual jitk
Executor integration are also UNVERIFIED by this area. Native pipes do not verify
EL0/EL1 containment, kernel control-byte enforcement, interrupts, or VMM watchdog
integration. D13 security implementation remains with its assigned owner.
No policy/credential layer, VMM containment change, second console, daemon or
second parser was added. All temporary qjs processes/containers were reaped.
